# Few-shot examples（汎用サンプル）

以下は **4セクション構成**の汎用例です。実際の発信者情報・商材・CTA は config から取得し、
相手企業の固有事実（`direct_signals` / `hook_context`）に合わせて Section 2・3 を書き分けます。

## 例1（単一フォーム / 件名なし）

入力（要約）: 業界=小売チェーン、固有事実=全国◯◯店舗・会員◯◯万人・新ECモール開設。

```json
{
  "subject": null,
  "body": "突然のご連絡で恐れ入ります。{sender.company} {sender.role}の{sender.name}と申します。{product.one_liner}に携わっております。\n\n貴社の全国◯◯店舗・会員◯◯万人という規模に加え、先日の新ECモール開設を拝見し、店舗とECの会員接点が分かれたままでは横断的なご案内設計に余地があるのではないかと感じております。特に季節商戦のタイミングは、本部側で事前のご案内を設計できるかどうかで成果が変わる論点と見受けられます。\n\n弊社では、購買履歴と来店データを統合した段階的なご案内設計に取り組んでまいりました。貴社の店舗×EC横断についても、本部主導の設計でお役に立てる余地があると考えております。\n\nよろしければ一度、オンラインでご提案のお時間を頂けないでしょうか。\n\nご多忙の折、誠に恐縮ですが、何卒よろしくお願い申し上げます。\n{pitch.call_to_action}"
}
```

## 例2（確認画面あり / 件名あり）

入力（要約）: 業界=サブスク/D2C、固有事実=定期通販主力・直近で解約率改善が課題との示唆。

```json
{
  "subject": "◯◯（固有事実）に関するCRM設計のご相談",
  "body": "突然のご連絡失礼いたします。{sender.company} {sender.role}の{sender.name}と申します。{product.one_liner}を行っております。\n\n定期通販を主力とされる貴社の事業構造ですと、新規獲得の後の継続接点の設計が成果を左右する論点になり得るのではないかと拝察しております。特に初回から2回目購入への移行期は、お客様層ごとの段階的なご案内が効きどころと見受けられます。\n\n弊社では、継続率改善と解約予兆の検知設計に取り組んでまいりました。貴社の定期顧客についても、購買履歴に基づく段階的なご案内設計でお役に立てればと考えております。\n\nよろしければ一度、オンラインでご提案のお時間を頂けないでしょうか。\n\nご多忙の折、誠に恐縮ですが、何卒よろしくお願い申し上げます。\n{pitch.call_to_action}"
}
```
