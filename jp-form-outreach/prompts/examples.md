# Few-shot Examples (v2)

各例は **意図的に異なる開き方・違うリズム** で書かれています。
全部を真似るのではなく、各例が示す「型」を理解して、当該targetに
最も合うものを選んで応用してください。

## ⚠️ 最重要・トーン上書き指示（v3 formal）

**Example 1 のトーン（丁寧版）を全例に適用してください。**
Example 2-6 は旧バージョンのカジュアル寄り表現が残っていますが、
構造（フック・自己紹介・CTA）だけを参考にし、文体は必ず Example 1 と
同じ最上級敬語に揃えてください。具体的には：

- 冒頭に「突然のご連絡で恐れ入ります」等の丁寧挨拶を置く（または挨拶を省いて固有事実から開始）
- 観察はすべて「〜と拝察しております」「〜と考えております」など仮説形式
- 自己紹介は「〜してまいりました者でございます」のトーン
- 「貴社」「弊社」「私ども」を用いる（「御社」は不可ではないが書き言葉では「貴社」を推奨）
- 結びは「お時間を頂戴できますと幸いに存じます」＋「何卒よろしくお願い申し上げます」の二段
- 「ですよね」「気になります」「効きそうです」「タイミングかと」「だなと感じます」など砕けた口語は使わない
- 「レバー」「穴」「刺さる」「効く」「食う」などの比喩・口語は使わない

## Example 1 — 数字フックで開く（D2C・上場）

**Target:**
```yaml
id: kitanotatsujin
name: 株式会社北の達人コーポレーション
industry: d2c_cosmetics_health
direct_signals:
  - "LINE for Business事例で3ヶ月で新規集客299%、北の快適工房"
  - "売上146億円(+49.2%)"
hook_context: |
  D2C上場、広告運用は超優秀、配信側CRM最適化に余地
```

**Output（440字）:**
```json
{
  "subject": null,
  "body": "突然のご連絡で恐れ入ります。3ヶ月で新規集客299%という北の快適工房のLINE広告事例、業界で繰り返し取り上げられている数字でございますが、本当に難しい論点はおそらく「獲得した友だちのその後」のほうではないかと拝察しております。\n\n株式会社トラーナの志田と申します。医療系のMDOnline立ち上げ後、ソニーグローバルエデュケーション様でこども向け定期サブスクのCRM設計を担当してまいりました者でございます。広告獲得の精度が高まっているフェーズでは、北の快適工房の定期解約予兆検知、北のフェアリーズ等の他ブランドへのクロスセルシナリオ、休眠顧客の掘り起こし、この3点が次に影響を与える領域になりやすいと考えております。\n\n既に貴社内で進められていらっしゃるようでしたら見当違いのご提案となり恐縮ですが、外部視点での論点整理が一度でもお役に立てそうであれば、30分ほどお時間を頂戴できますと幸いに存じます。\n\n何卒よろしくお願い申し上げます。\nカレンダー：https://tenbin.link/book/u-1302066f5d4f/torana-norimitsu-shida"

```

**型のポイント:**
- 冒頭は丁寧な挨拶＋固有事実への言及（1文目内で完結）
- 観察はすべて仮説形式（「拝察しております」「考えております」）で提示
- 自己紹介を中盤に、過去事業の文脈で挿入
- 結びは「見当違いでしたら恐縮」のOUT＋「お時間を頂戴できますと幸いに存じます」＋「何卒よろしくお願い申し上げます」の三段構え
- 「貴社」「拝読」「拝察」「存じます」など最上級敬語を自然に配置

## 自己点検チェックリスト（出力前に確認）

書き終わったら以下を確認してから出力：

- [ ] 1文目が「お世話になります」「突然」「初めまして」で始まっていないか
- [ ] 「拝見しました」「拝察します」「と存じます」が3回以上出ていないか
- [ ] 数字を使う場合、その会社の具体的な事業構造に紐づいているか
- [ ] 自己紹介が「肩書＋事例」のコピペになっていないか
- [ ] CTAに「OUTを残す控えめさ」または「具体的な価値提供」が含まれているか
- [ ] 段落数が機械的に3パラ揃いになっていないか
- [ ] 「両輪で」「ど真ん中」「直球」「ストライク」を使っていないか

NGに該当する場合、出力する前にもう一度書き直す。

## v4: 自己紹介段の差し替えバリエーション（トーンは Example 1 準拠）

同じ事実（MDOnline + ソニーグローバルエデュケーション）でも角度を変える。**連続2件で同じ V は NG。**

### V1. 医療領域起点（ヘルスケア宛て）

「医療領域 MDOnline を立ち上げ、患者と家族の二重顧客への接点設計をしてまいりました者として、トラーナの志田と申します。」

### V2. こども × サブスク起点（教育/D2C 宛て）

「ソニーグローバルエデュケーションでこども向け定期サブスクの CRM 設計に携わってまいりました者として、トラーナの志田と申します。」

### V3. 中堅企業 CRM 着眼起点（FC 型・本部運用宛て）

「中堅企業の本部主導 CRM が未整備という構造を、複数業界で見てきました者として、トラーナの志田と申します。」

### V4. 立場控えめ起点（大手宛て）

「弊社のような小さな組織から失礼いたします。継続率・LTV の設計を業界横断でしてまいりました、トラーナの志田と申します。」

### V5. 事業者起点（似た事業構造の企業宛て）

「私自身もサブスク事業の運営側におりました経験から、御社の…（続けて固有事実へ接続）— トラーナの志田と申します。」
