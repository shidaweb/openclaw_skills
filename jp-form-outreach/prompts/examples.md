# Few-shot Examples (v2)

各例は **意図的に異なる開き方・違うリズム** で書かれています。
全部を真似るのではなく、各例が示す「型」を理解して、当該targetに
最も合うものを選んで応用してください。

---

## Example 1 — 数字フックで開く（D2C・上場）

**Target:**
```yaml
id: kitanotatsujin
name: 株式会社北の達人コーポレーション
industry: d2c_cosmetics_health
direct_signals:
  - "LINE for Business事例で3ヶ月で新規集客299%、北の快適工房"
  - "売上146億円(+49.2%)"
hook_context: |
  D2C上場、広告運用は超優秀、配信側CRM最適化に余地
```

**Output（349字）:**
```json
{
  "subject": null,
  "body": "3ヶ月で新規集客299%という北の快適工房のLINE広告事例、業界で何度も話題にされていますが、あの数字の本当に難しい部分はおそらく「獲得した友だちのその後」のほうですよね。\n\n株式会社トラーナの志田と申します。医療系のMDOnlineを立ち上げた後、ソニーグローバルエデュケーションでこども向け定期サブスクのCRM設計をやってきた者です。広告は最適化が進んでいるほど、次のレバーは「配信側」になります。北の快適工房の定期解約予兆、北のフェアリーズなど他ブランドへのクロスセル、休眠掘り起こしの3点、御社の中ですでに優先順位がついていそうですが、もし聞き手が必要であれば30分だけ。\n\nもし既に動いていれば的外れで失礼します。\nカレンダー：https://tenbin.link/book/u-1302066f5d4f/torana-norimitsu-shida"
```

**型のポイント:**
- 冒頭が相手の有名な数字＋「実は難しいのはその先」という洞察。テンプレ挨拶ゼロ
- 自己紹介を中央に挿入、過去事業の文脈で
- 終わりに「OUT」を残す控えめなCTA

## 自己点検チェックリスト（出力前に確認）

書き終わったら以下を確認してから出力：

- [ ] 1文目が「お世話になります」「突然」「初めまして」で始まっていないか
- [ ] 「拝見しました」「拝察します」「と存じます」が3回以上出ていないか
- [ ] 数字を使う場合、その会社の具体的な事業構造に紐づいているか
- [ ] 自己紹介が「肩書＋事例」のコピペになっていないか
- [ ] CTAに「OUTを残す控えめさ」または「具体的な価値提供」が含まれているか
- [ ] 段落数が機械的に3パラ揃いになっていないか
- [ ] 「両輪で」「ど真ん中」「直球」「ストライク」を使っていないか

NGに該当する場合、出力する前にもう一度書き直す。
